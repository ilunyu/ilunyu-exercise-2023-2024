# [学年] 北京市《论语》题目汇总

本仓库保存一个学年的《论语》阅读试题资源。每个 JSON 文件是一道题目；主程序会读取这些文件生成阅读与学习应用的内容。

## 编辑题目

请使用 [ilunyu-exercise-editor](https://github.com/ilunyu/ilunyu-exercise-editor) 编辑题目。编辑器是本地 Flask 工具，负责维护富文本格式、缩进、下划线、着重点和原文关联；不要手工修改字符区间。

```bash
git clone https://github.com/ilunyu/ilunyu-exercise-editor.git
cd ilunyu-exercise-editor
python -m pip install -r requirements.txt
python app.py --root /绝对路径/[本仓库目录] --port 8090
```

在浏览器打开 <http://127.0.0.1:8090/>。提交前请检查 Git diff，并运行本仓库的校验：

```bash
python3 tools/validate_exercises.py
```

详细格式见 [docs/SCHEMA.md](docs/SCHEMA.md)，可复制 [examples/202611-example.json](examples/202611-example.json) 作为新题目的起点。

## 新建年度仓库后需更新的内容

1. 将仓库名称改为 `ilunyu-exercise-YYYY-YYYY`。
2. 将本 README 的标题、统计数字、各区考察矩阵与评述替换为该学年信息。
3. 删除 `examples/202611-example.json`；样例不属于正式题库。
4. 新题目文件必须放在仓库根目录，文件名必须严格等于其 JSON 的 `id`，即 `<id>.json`。
